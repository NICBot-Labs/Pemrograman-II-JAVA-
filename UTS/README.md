📦 Inventory Produk – Gudang A & Gudang B (UMKM)

Aplikasi inventaris produk untuk Gudang A dan Gudang B yang dikembangkan sebagai project UTS Semester 3 – Pemrograman 2.
Dibangun menggunakan Java GUI (NetBeans 8.2) dengan penerapan konsep OOP.

🖥️ Tech Stack

Java (NetBeans 8.2)

Java Swing (GUI)

Object Oriented Programming (OOP)

🧩 GUI Components

Containers: JFrame, JPanel

Controls: JButton, JTextField, JCheckBox

Menus: JMenuBar, JMenu, JMenuItem

🧠 OOP Concepts Used

Inheritance – Pewarisan atribut dan method dari class induk

Encapsulation – Pengamanan data menggunakan access modifier

Polymorphism – Method dengan nama sama, perilaku berbeda

Parameterized Method – Method dengan parameter input

Object Composition – Penggunaan objek dalam class lain

📊 UML

Class Diagram

Relasi antar class (OOP connectivity)

🎯 Features

Manajemen inventaris Gudang A

Manajemen inventaris Gudang B

Input, update, dan tampilan data produk

Navigasi menu berbasis GUI

📌 Purpose

Project ini dibuat untuk memenuhi UTS Semester 3 – Mata Kuliah Pemrograman 2 dengan studi kasus inventaris produk UMKM.
